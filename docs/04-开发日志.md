## 2026-07-13

### [项目初始化] 搭建项目骨架
**用时：** 约 30 分钟
**完成内容：**
- 创建 `app/`、`app/core/`、`app/models/`、`app/schemas/`、`data/`、`scripts/` 等目录结构
- 创建 `requirements.txt`，放宽版本约束以兼容 Python 3.14
- 实现 `app/core/config.py`：使用 pydantic-settings 管理全局配置（数据库路径、LLM 配置、退款阈值）
- 实现 `app/core/database.py`：SQLAlchemy 2.0 同步引擎 + init_db 自动建表 + get_db 依赖注入
- 实现 `app/main.py`：FastAPI 应用入口，startup 时自动 init_db，提供 `/api/health` 健康检查端点
**遇到的问题：**
- 系统 Python 为 3.14.2（而非项目规划的 3.13），pydantic-core 无预编译 wheel，从源码编译时 Rust linker 失败
- Git Bash 终端 GBK 编码不支持 emoji 字符，print 报错
**解决方案：**
- requirements.txt 改为 `>=` 版本约束，利用系统已安装的 pydantic 2.13.1 等新版本
- 种子数据脚本中去掉 emoji，使用普通文本标记
**学到什么：**
- Python 3.14 是新版本，部分包尚未发布 wheel，需放宽版本约束
- pydantic-settings 的 `model_config` 在 v2 中更名为 `Config` 类方式

**用时：** 约 40 分钟
**完成内容：**
- 6 个 SQLAlchemy 模型（user/product/order/ticket/agent_trace/unresolved_case）全部实现
- 为 agent_trace 和 ticket 添加了设计说明注释（为什么用单表、为什么 JSON 字段等）
- 种子数据脚本 `scripts/seed_data.py`：3 用户 + 6 款男装羽绒服 + 6 个订单
- 商品数据覆盖不同价位（199-499 元）和场景（极寒、轻薄、户外、商务、短款、长款）
- 订单 10003（pending）专为 Phase 5 退款测试设计（399 > 100 阈值）
- 订单 10004（refunded）用于测试重复退款拦截
