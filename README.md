# FashionAgent 服装电商智能客服 Agent

FashionAgent 是一个面向服装电商企业客服场景的智能业务 Agent 系统。它不是简单的聊天机器人，而是能接入企业内部数据、理解用户意图、调用业务工具、执行售后流程、在必要时触发人工审核的可评测业务系统。

## 项目背景

服装电商客服每天处理大量重复性问题——商品材质咨询、尺码推荐、订单查询、退换货处理。传统客服模式存在成本高、回复不统一、夜间响应弱、高峰期积压严重等问题。同时，退款等涉及资金的操作又不能完全交给 AI 自动执行。

FashionAgent 的解决思路：将大模型能力嵌入真实业务流程，普通问题自动处理，高风险操作进入人工审核，整个过程可追踪、可评测、可复盘。

## 核心功能

| 功能 | 说明 | 关键技术 |
|------|------|---------|
| 商品知识咨询 | 基于 RAG 检索企业商品知识库，回答材质、尺码、洗护等问题 | RAG、向量检索 |
| 智能尺码推荐 | 根据身高体重和穿衣偏好，调用规则工具推荐尺码 | Tool Calling、信息抽取 |
| 订单查询 | 通过查询工具获取订单状态、物流信息 | Tool Calling、数据库查询 |
| 售后退款审核 | 小额自动处理，大额触发人工审核工单 | Human-in-the-loop、风险控制 |

## 技术架构

```
用户输入 → Web 前端 → FastAPI → LangGraph Agent 工作流
                                      │
              ┌───────────────────────┼───────────────────┐
              │                       │                   │
           RAG 知识检索           Tool 调用          人工审核
              │                       │                   │
         Vector DB (Chroma)    业务数据库 (SQLite)    工单系统
              │                       │                   │
              └───────────────────────┼───────────────────┘
                                      │
                                Trace + 评测
```

### 技术栈

| 层次 | 技术 | 选型理由 |
|------|------|---------|
| 后端框架 | Python FastAPI | 异步支持好，生态成熟 |
| Agent 编排 | LangGraph | 适合有状态、多分支的业务流程 |
| 向量数据库 | Chroma | 开发阶段零部署成本，后续可迁移 |
| 数据库 | SQLite → MySQL | 开发用 SQLite，生产可平滑迁移 |
| 大模型 | OpenAI / 兼容 API | 接口统一，可替换 |

## 四类业务处理流程

### 1. 商品咨询
用户提问 → Router 识别为知识咨询 → RAG 检索商品知识库 → 生成回答

### 2. 尺码推荐
用户输入身高体重 → Router 识别为尺码推荐 → 调用尺码工具 → 返回推荐结果

### 3. 订单查询
用户查询订单 → Router 识别为订单查询 → 调用订单工具 → 返回订单状态

### 4. 售后退款
用户申请退款 → Router 识别为退款请求 → 查询订单 → 检索售后规则 → 风险判断 → 小额自动处理 / 大额人工审核

## 评测指标

| 指标 | 说明 |
|------|------|
| RAG Top-1 / Top-3 Recall | 知识召回命中率 |
| Intent Accuracy | 意图识别准确率 |
| Tool Success Rate | 工具调用成功率 |
| Auto Resolution Rate | 自动处理比例 |
| Human Review Trigger Accuracy | 人工审核触发准确率 |

## 快速开始

```bash
cd FashionAgent

# 安装依赖
pip install -r requirements.txt

# 初始化数据库
python scripts/seed_data.py

# 启动服务
python app/main.py

# 访问
http://localhost:8000
```
