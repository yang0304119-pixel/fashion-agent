# 售后退款规则

> 类型：售后规则
> 适用品类：服装通用
> 最后更新：2026-07-14

---

## 一、退货政策总则

### 1.1 七天无理由退货

根据《中华人民共和国消费者权益保护法》，消费者有权在收到商品之日起 **七日内** 无理由退货。

| 条件 | 说明 |
|------|------|
| 适用对象 | 线上购买的商品（非定制/非贴身内衣等特殊品类） |
| 时间计算 | 签收次日 0 点起算，第 7 日 24 点前申请 |
| 费用承担 | 消费者承担退货运费（商家责任除外） |
| 商品要求 | 不影响二次销售（未穿着、未洗涤、吊牌完整、包装完好） |

### 1.2 不适用七天无理由的情况

- 定做/定制商品（如绣字、改尺寸）
- 贴身内衣裤（出于卫生考虑）
- 已穿着/已洗涤/影响二次销售的商品
- 超过退货期限（签收后 7 天以上）

## 二、质量问题处理

### 2.1 质量问题的定义

符合以下任一情形可认定为质量问题：

| 类型 | 具体表现 |
|------|---------|
| 面料缺陷 | 破洞、抽丝、起球严重（非正常穿着导致）、面料染色不均 |
| 做工问题 | 开线、缝位不齐、左右不对称（偏差超过 1cm） |
| 配件问题 | 拉链卡死/断裂、纽扣脱落/缺失、魔术贴失效 |
| 污损 | 明显污渍（非消费者造成）、发霉 |
| 描述不符 | 材质/颜色/尺码与商品详情页显著不符 |
| 错发漏发 | 收到的商品与订单不一致、数量缺失 |

### 2.2 质量问题处理流程

```
消费者申请 → 上传凭证（照片/视频）→ 商家审核 → 确认质量问题
  → 方案 A：全额退款 + 商家承担退货运费
  → 方案 B：免费换货（同款同码，商家承担来回运费）
  → 方案 C：部分退款（不影响使用的轻微瑕疵，协商补偿）
```

### 2.3 非质量问题的常见情况

以下情况 **不属** 于质量问题，不支持因质量问题产生的退换货：

- 轻微色差（受显示器和拍摄光线影响，但色差过大除外）
- 线头未修剪（剪掉即可，不属于瑕疵）
- 新旧款版型差异（非质量问题，属于正常产品迭代）
- 主观感受（"感觉不好看""觉得不值"建议走七天无理由）
- 尺码不合适（建议换货或走七天无理由）

### 2.4 争议处理

消费者和商家对质量问题认定不一致时：

```
消费者 → 提供清晰凭证 → 商家重新审核
  → 仍不一致 → 平台介入调解
    → 仍无法解决 → 建议消费者走第三方渠道（12315）
```

## 三、退款规则

### 3.1 退款类型

| 退款类型 | 说明 | 退款金额 |
|---------|------|---------|
| 仅退款 | 商品退回后退款 | 商品实付金额 |
| 退货退款 | 商品退回后退款 | 商品实付金额（运费视情况） |
| 部分退款 | 商品保留，部分金额退还 | 协商确定 |
| 缺货退款 | 商家无法发货 | 全额退款 |
| 赔付退款 | 商家违约（延迟发货/错发等） | 全额退款 + 平台赔付（如有） |

### 3.2 自动处理规则

符合以下条件的退款申请可由系统自动处理：

| 条件 | 自动处理方式 |
|------|-------------|
| 退款金额 ≤ 100 元 + 规则明确 | 自动审批通过 |
| 7 天内无理由退货 | 自动通过 |
| 已退款订单的重复申请 | 自动拒绝（提示已处理） |

### 3.3 人工审核条件

以下情况需人工审核（工单制）：

| 条件 | 原因 |
|------|------|
| 退款金额 > 100 元 | 金额较大，需人工确认 |
| 质量问题认定 | 需要人工查看凭证 |
| 超过退换货期限 | 特殊申请，需人工评估 |
| 已退款订单再次申请 | 防止重复退款 |
| 消费者投诉/纠纷 | 需要人工介入处理 |
| 规则不明确/无法判定 | 升级人工处理 |

### 3.4 退款拦截（不可重复处理）

```
已退款订单 → 消费者再次申请该订单退款
  → 系统自动拦截（提示：该订单已完成退款）
  → 如消费者有异议 → 转人工处理
```

## 四、换货规则

### 4.1 换货适用场景

| 场景 | 说明 |
|------|------|
| 尺码不合适 | 七天无理由换货，运费消费者承担 |
| 质量问题 | 免费换货，运费商家承担 |
| 错发商品 | 免费换货，运费商家承担 |
| 颜色/款式不符心意 | 走七天无理由→重新下单，或协商换货 |

### 4.2 换货流程

```
消费者申请 → 商家审核 → 消费者寄回商品
  → 商家验收（检查不影响二次销售）
  → 商家发出新商品 → 消费者确认收货
```

### 4.3 换货注意事项

- 换货库存以商家实时库存为准，如缺货可转为退款
- 换货仅限同款商品的尺码/颜色更换，不能换其他款
- 质量问题换货的来回运费均由商家承担
- 非质量问题换货的寄回运费由消费者承担

## 五、常见售后问题 FAQ

**Q：退货的运费谁出？**
A：质量问题/商家责任 → 商家出。七天无理由/不喜欢/尺码不合适 → 消费者出。

**Q：吊牌剪了还能退吗？**
A：吊牌剪掉会影响二次销售，通常不支持七天无理由退货。但如果是质量问题，剪了吊牌也可以退。

**Q：洗过一次发现质量问题还能退吗？**
A：可以。正常洗涤一次后发现的隐蔽瑕疵（如面料抽丝、掉色严重）属于质量问题，可以退。但如果因洗涤方式不当导致的损坏（如热水洗羊毛导致缩水），则不属于质量问题。

**Q：退货多长时间能收到退款？**
A：商家收到退货并验收后，通常在 1-3 个工作日内退款到账。使用信用卡/花呗支付的，可能延迟至 3-7 个工作日。

**Q：我不小心点了确认收货，还能申请退款吗？**
A：可以。确认收货不影响售后权益，在退货时效内均可正常申请退款或换货。

**Q：能否只退款不退货？**
A：需双方协商。小额订单（50 元以下）或商品价值较低的，商家可能同意仅退款不退货。金额较大的通常需退回商品。

**Q：商品在运输途中损坏了怎么办？**
A：签收前发现包装破损，建议拒收。签收后发现商品损坏，请在 24 小时内联系客服并提供照片/视频，由商家向快递公司索赔。
