# 面料种类与洗护指南

> 类型：商品知识
> 适用品类：服装通用
> 最后更新：2026-07-14

## 一、常见服装面料速查

### 1.1 天然纤维

| 面料 | 来源 | 特点 | 常见用途 |
|------|------|------|---------|
| **棉（Cotton）** | 棉花的种子纤维 | 吸湿透气、柔软舒适、易皱缩水 | T恤、衬衫、内衣、牛仔裤 |
| **羊毛（Wool）** | 绵羊的毛 | 保暖性好、弹性佳、可吸收水分不感潮湿 | 毛衣、大衣、围巾 |
| **羊绒（Cashmere）** | 山羊的底层绒毛 | 极柔软、轻暖、价格高 | 高档毛衣、大衣 |
| **真丝（Silk）** | 蚕丝 | 光滑柔顺、透气、对皮肤友好 | 衬衫、连衣裙、睡衣 |
| **亚麻（Linen）** | 亚麻植物的茎皮 | 透气性极好、吸汗、易皱 | 夏装、衬衫、裤子 |

### 1.2 合成纤维

| 面料 | 来源 | 特点 | 常见用途 |
|------|------|------|---------|
| **聚酯纤维（Polyester）** | 石油化工合成 | 抗皱、快干、不易缩水、透气性差 | 羽绒服外套、运动服、夹克 |
| **尼龙（Nylon）** | 石油化工合成 | 强度高、耐磨、弹性好、防钻绒 | 羽绒服面料、冲锋衣、背包 |
| **氨纶（Spandex/Elastane）** | 石油化工合成 | 弹性极佳、常与其他纤维混纺以增加弹力 | 运动服、修身裤、内衣 |
| **腈纶（Acrylic）** | 石油化工合成 | 外观像羊毛、保暖、轻便、易起球 | 毛衣替代品、毛毯 |
| **粘胶纤维（Viscose）** | 天然木浆再生 | 像丝一样柔滑、吸湿、易缩水 | 连衣裙、衬衫、里料 |

### 1.3 常见混纺面料

| 混纺比例 | 特点 | 常见用途 |
|---------|------|---------|
| 聚酯纤维 100%（带涂层） | 防风防水、耐磨 | 冲锋衣外壳、羽绒服面料 |
| 88% 聚酯纤维 + 12% 氨纶 | 四面弹力、抗皱、修身 | 商务修身外套、运动外套 |
| 棉 60% + 聚酯纤维 40% | 柔软又抗皱、不易缩水 | 休闲衬衫、T恤 |
| 羊毛 90% + 氨纶 10% | 保暖又有弹力 | 修身羊毛大衣 |
| 聚酯纤维 100% + PU 涂层 | 防水防风、不透气 | 雨衣、防寒服外层 |

## 二、羽绒服专项知识

### 2.1 核心参数解析

| 参数 | 含义 | 参考范围 |
|------|------|---------|
| **充绒量** | 羽绒服里填充的羽绒总重量（克） | 轻薄款 50-100g / 常规 100-180g / 极寒 180-300g |
| **含绒量** | 羽绒中绒子所占的百分比（剩下是羽毛） | 国标要求 >= 50%，品质款 >= 80% |
| **蓬松度（FP）** | 一盎司羽绒所占的体积（立方英寸） | 常规 600-700FP / 高品质 700-800FP / 顶级 800+FP |
| **羽绒种类** | 白鹅绒 / 灰鹅绒 / 白鸭绒 / 灰鸭绒 | 鹅绒保暖性优于鸭绒，但差距不大 |

### 2.2 不同充绒量的适用温度

| 充绒量 | 适用场景 | 参考温度 |
|-------|---------|---------|
| 50-80g | 春秋季、初冬、南方地区 | 5°C 至 15°C |
| 80-120g | 常规冬季、中部地区 | -5°C 至 5°C |
| 120-180g | 深冬、北方地区 | -15°C 至 -5°C |
| 180g+ | 极寒、东北/高寒环境 | 低于 -15°C |

### 2.3 羽绒服常见问题

**Q：羽绒服会钻绒吗？**
A：任何羽绒服都有轻微钻绒现象，但高品质面料（高密度尼龙/聚酯纤维+防钻绒涂层）能显著减少。偶尔几根钻出属于正常现象，不属于质量问题。

**Q：羽绒服可以机洗吗？**
A：建议手洗或专业干洗。机洗可能损坏羽绒结构。如要机洗须用滚筒洗衣机、中性洗涤剂、低速轻柔模式。

**Q：羽绒服洗完不蓬松了怎么办？**
A：晾干后轻拍或用低温烘干机（放网球一起烘）帮助羽绒重新蓬松。

**Q：鹅绒和鸭绒哪个好？**
A：鹅绒绒朵更大、蓬松度更高、保暖性略好、异味更少。但日常穿着鸭绒已经足够，性价比更高。

## 三、面料洗护通用规则

### 3.1 洗涤标签解读

国际通用的洗护标签符号：

| 符号 | 含义 |
|------|------|
| 🧺 水盆 + 数字（如 30） | 最高洗涤温度（°C） |
| 🧺 水盆 + 手 | 仅能手洗 |
| 🔺 三角形 | 可使用漂白剂（X=不可漂白） |
| 🔺 三角形 + 斜线 | 仅可用非氯漂白剂 |
| 🔲 圆圈 | 专业干洗 |
| 🔲 圆圈 + X | 不可干洗 |
| 👕 熨斗 + 点 | 可熨烫（1点=低温/2点=中温/3点=高温） |
| 👕 熨斗 + X | 不可熨烫 |
| ⭕ 正方形 + 竖线 | 悬挂晾干 |
| ⭕ 正方形 + 横线 | 平铺晾干 |
| ⭕ 正方形 + X | 不可水洗 |

### 3.2 常见面料洗护指南

| 面料 | 洗涤方式 | 晾干方式 | 熨烫 | 注意事项 |
|------|---------|---------|------|---------|
| **棉** | 30-40°C 机洗 | 悬挂晾干 | 中温熨烫 | 深色棉衣初次洗涤可能掉色，建议单独洗 |
| **羊毛** | 30°C 冷水手洗/干洗 | 平铺晾干（不可悬挂） | 低温蒸汽熨烫 | 不可机洗、不可拧干、不可暴晒 |
| **聚酯纤维** | 30-40°C 机洗 | 悬挂晾干 | 低温熨烫 | 耐洗易干，但高温易变形 |
| **尼龙** | 30°C 冷水洗 | 悬挂阴干 | 不可熨烫或极低温 | 不耐高温，远离开火源 |
| **真丝** | 30°C 冷水手洗/干洗 | 阴干、不可暴晒 | 低温反面熨烫 | 不可碱性洗涤剂、不可拧干 |
| **羽绒服** | 30°C 冷水手洗/专业干洗 | 阴干/低温烘干+轻拍 | 不可熨烫 | 不可干洗（部分可），不可用柔顺剂 |
| **冲锋衣** | 专业冲锋衣洗涤剂洗 | 悬挂晾干 | 低温熨烫恢复防泼水 | 不可柔顺剂、不可漂白 |

### 3.3 洗护禁忌清单

| ❌ 禁止做法 | 为什么 |
|-----------|--------|
| 用热水洗羊毛/真丝 | 严重缩水，不可逆 |
| 用漂白剂洗彩色衣服 | 褪色、损坏纤维 |
| 用力拧干毛衣 | 变形，失去弹性 |
| 暴晒真丝/羊毛 | 发黄、变脆 |
| 高温熨烫化纤面料 | 熔化、粘连 |
| 羽绒服干洗（部分情况） | 化学溶剂破坏羽绒天然油脂 |

## 四、常见面料问答 FAQ

**Q：这件衣服会起球吗？**
A：任何面料穿久了都可能起球，尤其是摩擦多的部位（袖口、腋下、领口）。**腈纶和羊毛混纺**最容易起球，**高支棉和平滑聚酯纤维**不易起球。轻微起球可用毛球修剪器处理，不影响穿着。

**Q：会缩水吗？**
A：**纯棉和羊毛**首次洗涤可能缩水 3-5%（正常现象）。建议购买时参考大一码，或按洗护标签选择冷水洗/干洗。聚酯纤维和尼龙几乎不缩水。

**Q：黑色衣服褪色怎么办？**
A：深色衣服初次洗涤会轻微掉色，建议：① 前 3 次用冷水单独洗 ② 翻面洗 ③ 加一勺盐或白醋固色 ④ 不要暴晒。

**Q：羽绒服怎么去味？**
A：通风晾晒即可（避免暴晒）。如因存放产生霉味，可用湿布擦拭后通风。如果是新羽绒服的鸭绒味，正常通风 1-2 天即消散。

**Q：防水面料的衣服还能恢复防水性吗？**
A：可购买专业的 DWR（耐久防水）喷雾，清洗后在半干状态下喷洒，低温熨烫即可恢复防泼水效果。
