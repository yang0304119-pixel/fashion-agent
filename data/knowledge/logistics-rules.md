# 物流与配送规则

> 类型：物流规则
> 适用品类：服装通用
> 最后更新：2026-07-14

---

## 一、发货时效

### 1.1 常规商品发货时间

| 订单类型 | 发货时间 | 说明 |
|---------|---------|------|
| 现货商品 | 24-48 小时内 | 工作日计算，周末和节假日顺延 |
| 预售商品 | 按商品详情页标注时间 | 以页面"预计发货时间"为准 |
| 定制商品 | 3-7 个工作日 | 如定制logo、改尺寸等 |

### 1.2 延迟发货处理

- 商家未在承诺时间内发货，消费者可申请延迟发货赔付
- 赔付标准：订单金额的 **5%**（最低 5 元，最高 50 元）
- 延迟超过 **72 小时**，消费者可申请退款

### 1.3 缺货处理

- 商家因库存不足无法发货的，需在 24 小时内主动联系消费者说明
- 消费者可选择：① 全额退款 ② 换货（同价其他款式）③ 等待补货（补货时间需双方协商）

## 二、配送范围与时效

### 2.1 配送方式

| 配送方式 | 适用场景 | 参考时效 |
|---------|---------|---------|
| 普通快递 | 全国大部分地区 | 3-7 个工作日 |
| 加急快递 | 急需订单 | 1-3 个工作日 |
| 顺丰速运 | 高价值商品/消费者指定 | 1-3 个工作日 |
| 同城配送 | 同城急用 | 当日/次日达 |
| 自营物流 | 有自营物流能力的商家 | 按商家承诺时效 |
| 国际配送 | 海外订单/跨境物流 | 7-20 个工作日 |

### 2.2 全国配送时效参考（普通快递）

| 区域 | 包含省份 | 参考时效 |
|------|---------|---------|
| 华东 | 上海、江苏、浙江、安徽 | 2-3 天 |
| 华北 | 北京、天津、河北、山西、山东 | 2-4 天 |
| 华南 | 广东、福建、海南、广西 | 2-4 天 |
| 华中 | 河南、湖北、湖南、江西 | 3-5 天 |
| 西南 | 四川、重庆、云南、贵州 | 3-6 天 |
| 西北 | 陕西、甘肃、宁夏、青海、新疆 | 5-7 天 |
| 东北 | 辽宁、吉林、黑龙江 | 3-6 天 |
| 偏远地区 | 西藏、新疆部分地区、青海部分地区 | 7-15 天 |

> 以上时效为参考值，实际受天气、交通、节假日等因素影响。

### 2.3 偏远地区说明

以下地区因配送难度较大，可能存在：
1. 配送时效延长（7-15 天）
2. 需额外加收偏远地区运费
3. 部分物流公司可能无法配送至乡镇/村级地址

建议购买前咨询客服确认配送可行性。

## 三、运费规则

### 3.1 运费标准

| 条件 | 运费 |
|------|------|
| 订单满 **199 元** | **包邮**（偏远地区除外） |
| 订单不满 199 元 | 按实际重量/件数收取，参考价 8-15 元 |
| 偏远地区（新疆/西藏等） | 按实际运费收取 |
| 顺丰速运（消费者要求） | 消费者承担差价 |

### 3.2 包邮规则说明

- 包邮仅限普通快递（中通/圆通/韵达/申通/邮政等）
- 偏远地区不参与包邮活动
- 包邮订单退货时，退款金额 = 订单金额 - 发货运费（如商家承担了发货运费）
- 活动期间（如双11/618）的包邮规则以活动详情为准

### 3.3 退换货运费

见《售后规则》第五章，总结如下：

| 情况 | 寄回运费 | 重发运费 |
|------|---------|---------|
| 质量问题退/换货 | 商家承担 | 商家承担 |
| 七天无理由退货 | 消费者承担 | — |
| 尺码不合适换货 | 消费者承担 | 商家承担 |
| 错发漏发 | 商家承担 | 商家承担 |

## 四、快递状态与查询

### 4.1 常见快递状态说明

| 状态 | 含义 |
|------|------|
| 已揽收 | 快递员已取走包裹，进入快递系统 |
| 运输中 | 包裹在运输途中（长途/中转） |
| 到达派件网点 | 包裹已到达目的地城市，准备派送 |
| 派送中 | 快递员正在派送 |
| 已签收 | 包裹已送达并签收 |
| 异常 | 包裹在运输中出现异常（延误/破损/退回等） |

### 4.2 物流异常处理

| 异常情况 | 建议处理方式 |
|---------|------------|
| 物流信息长时间不更新（超过 3 天） | 联系商家，商家向快递公司查询 |
| 显示已签收但未收到货 | ① 检查是否家人/同事代收 ② 检查快递柜/驿站 ③ 联系快递员 |
| 包裹破损/变形 | 当着快递员面验货，如损坏可拒签 |
| 物流信息显示退回 | 联系商家确认原因（地址错误/联系不上/拒收等） |

## 五、拒收与退件处理

### 5.1 拒收条件

消费者可在以下情况拒收包裹：
- 包裹外观明显破损/变形/水渍
- 到付运费与订单不符
- 未经消费者同意改配送方式
- 商品与订单明显不符（如颜色/数量一眼可见的错误）

### 5.2 拒收后处理

```
消费者拒收 → 包裹退回商家 → 商家验收
  → 确认商品完好 → 消费者申请退款
  → 确认商品有损 → 协商处理
```

- 拒收后退款时效：商家收到退回包裹后 1-3 个工作日
- 拒收运费：如因消费者原因拒收（不想要/后悔），运费由消费者承担
- 如因商家原因（错发/破损），运费由商家承担

### 5.3 地址异常

- 地址填写错误导致退回 → 消费者承担退回运费
- 需修改地址 → 未发货前可联系客服修改；已发货则需联系快递公司转寄（可能产生转寄费）

## 六、常见物流问题 FAQ

**Q：下单后多久能看到物流信息？**
A：商家发货后，物流信息通常在 2-12 小时内更新。如果超过 24 小时仍未更新，建议联系商家确认是否已发出。

**Q：可以指定快递公司吗？**
A：普通订单默认安排合作快递，不指定快递公司。如有特殊需求需指定顺丰等快递，可联系客服并承担运费差价。

**Q：包裹显示签收但我没收到怎么办？**
A：先检查：① 是否被放在了快递柜/驿站 ② 家人/同事/门卫是否代收 ③ 快递是否投递到了其他地址。确认未收到后联系商家，商家会向快递公司发起查询。

**Q：节假日发货吗？**
A：法定节假日期间的发货时效会延长。一般节假日期间的订单会在节后按顺序发出。具体时效请关注商品页面的公告。

**Q：可以送到港澳台或海外吗？**
A：需咨询客服确认。港澳台地区部分商家支持配送（运费自理），海外配送需根据具体国家和商品类型确认。
