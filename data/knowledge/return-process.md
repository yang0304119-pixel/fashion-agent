# 退款换货操作流程

> 类型：售后规则
> 适用品类：服装通用
> 最后更新：2026-07-15

---

## 一、七天无理由退货流程

### 适用条件
- 签收次日起7天内申请
- 商品未穿着、未洗涤、吊牌完整、包装完好
- 不影响二次销售

### 操作步骤

**步骤1：提交申请**
- 联系在线客服或在订单页面点击"申请退款/退货"
- 选择退货原因（七天无理由/质量问题/其他）
- 提交后等待客服审核

**步骤2：客服审核**
- 客服在24小时内审核申请
- 审核通过 → 系统推送退货地址
- 审核不通过 → 客服联系说明原因

**步骤3：寄回商品**
- 按退货地址寄回，建议选择有物流跟踪的快递
- 包装好商品，确保吊牌和附件齐全
- 七天无理由退货：运费由买家承担
- 质量问题退货：先垫付运费，收货后退还

**步骤4：收货验货**
- 仓库收到商品后1-2个工作日验货
- 验货通过 → 发起退款
- 验货不通过（如发现穿着痕迹、吊牌缺失） → 联系买家协商

**步骤5：退款到账**
- 退款原路返回
- 微信/支付宝支付：1-3个工作日到账
- 银行卡支付：3-7个工作日到账

### 退款金额计算

| 场景 | 退款金额 |
|------|---------|
| 订单未发货 | 全额退款 |
| 已发货/已签收-七天无理由 | 商品金额 - 退货运费 |
| 质量问题 | 全额退款（含发货运费） |
| 部分商品退货 | 按商品单价比例退 |

## 二、质量问题处理流程

### 质量问题范围
- 面料破损、破洞
- 明显污渍（非人为造成）
- 拉链/纽扣损坏
- 缝线严重脱线
- 版型严重不对称

### 处理流程

1. **签收后48小时内**联系客服，附照片或视频
2. 客服判断是否属于质量问题（24小时内回复）
3. 确认质量问题 → 提供退货地址，运费本店承担
4. 寄回商品，建议使用可追踪快递
5. 仓库收货验货后，原路退款或发出换货

### 注意事项
- 超过48小时反映质量问题，需提供视频或连续照片证明非人为损坏
- 洗涤后发现问题无法认定为质量问题（洗涤方式不当可能造成损坏）
- 少量线头属于正常工艺痕迹，自行剪掉即可，不属于质量问题

## 三、换货流程

### 换货条件
- 签收次日起7天内
- 商品完好（同上条件）
- 仅支持同款换尺码/颜色，不支持跨款式换货

### 操作步骤

1. 联系客服说明换货需求（换什么尺码/颜色）
2. 客服确认库存后，提供换货退货地址
3. 寄回商品（运费买家承担，质量问题除外）
4. 仓库收到后1-2个工作日发出新货
5. 换货发出后，系统发送新物流单号

### 换货时效
- 仓库收到退货后1-2个工作日内发货
- 换货寄出后配送时间同正常订单

## 四、退款到账时间说明

| 支付方式 | 退款到账时间 |
|---------|------------|
| 微信支付 | 1-3个工作日 |
| 支付宝 | 1-3个工作日 |
| 银行卡 | 3-7个工作日 |
| 余额/积分支付 | 即时到账 |

### 退款进度查询
- 微信：我 → 服务 → 钱包 → 账单 查看
- 支付宝：我的 → 账单 查看
- 银行卡：联系发卡行查询

## 五、特殊情况处理

### 订单已发货但未签收，想退款
- 联系客服拦截快递
- 拦截成功 → 全额退款（无需寄回）
- 拦截失败 → 收到后退货处理

### 退款申请被拒怎么办
常见原因：
- 超过退货期限 → 建议转维修或协商补偿
- 商品已使用/洗涤 → 无法二次销售，恕不能退
- 非本店商品 → 核对订单信息

### 退货物流显示签收但未收到退款
- 仓库验货需1-2个工作日，建议等待
- 超过2个工作日仍未退款 → 联系客服提供物流单号查询

### 赠品需要退回吗
- 无损退回：赠品需随商品一并退回
- 赠品已使用或丢失：按赠品价值从退款中扣除
