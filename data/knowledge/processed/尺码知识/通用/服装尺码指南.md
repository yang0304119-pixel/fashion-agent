### 1.2 羽绒服/棉服（含充绒量参考）

羽绒服因充绒量和面料厚度不同，实际版型可能比普通外套偏大或偏小。建议在常规尺码基础上参考以下因素：

| 版型类型 | 建议 |
|---------|------|
| 修身版（Slim Fit） | 按标准尺码选，胸围偏紧 |
| 标准版（Regular Fit） | 按标准尺码选 |
| 宽松版（Relaxed Fit） | 可买小一码 |
| 加厚款（充绒量 180g+） | 建议买大一码，内里空间更大更舒适 |

## 三、常见偏码说明

### 3.1 不同版型的尺码差异

| 版型 | 特征 | 选码建议 |
|------|------|---------|
| 欧版 | 整体偏大，袖子偏长 | 买小一码 |
| 日版 | 整体偏小，肩宽偏窄 | 买大一码 |
| 韩版 | 衣长偏短，肩宽偏窄 | 买大一码 |
| 国产标准 | 符合上表标准 | 按表选即可 |

### 3.2 常见商品类型的版型特点

- **羽绒服：** 因充绒膨胀，建议按标准码或大一码选择，尤其是内搭厚毛衣时
- **冲锋衣：** 外壳偏硬，需预留内层空间，建议按大一码选择
- **修身衬衫：** 胸围和腰围偏紧，建议按标准码选，如偏胖酌情大一码
- **运动卫衣：** 版型偏宽松，可按标准码或小一码选

## 四、如何正确测量身体尺寸

### 4.1 测量工具
- 软尺（皮尺），没有软尺可用绳子 + 直尺替代

### 4.2 测量方法

| 部位 | 测量方式 |
|------|---------|
| **身高** | 赤脚靠墙站立，用水平物（书）压头顶，标记高度后测量 |
| **胸围** | 软尺水平绕过胸部最丰满处，保持软尺与地面平行，不勒紧 |
| **腰围** | 自然站立，软尺绕腰部最细处（肚脐上方约2cm），保持正常呼吸 |
| **臀围** | 双腿并拢，软尺绕臀部最丰满处 |
| **肩宽** | 从左肩骨外侧到右肩骨外侧的直线距离 |
| **衣长** | 从肩颈点垂直量至所需下摆位置 |
| **袖长** | 从肩点量至手腕骨处，手臂自然弯曲 |
| **裤长** | 从腰头量至裤脚，或从腰线量至脚踝下方 |

### 4.3 测量注意事项
- 建议穿着贴身衣物测量，不要穿厚外套
- 量腰围时保持自然呼吸，不要刻意收腹
- 如果介于两个尺码之间：偏好修身选小码，偏好宽松选大码
- 不确定时建议咨询客服或参考往期购买记录

## 五、常见尺码问题 FAQ

**Q：我175cm、70kg，应该穿什么码？**
A：根据速查表，175cm/70kg 交叉为 L 码。如果偏好修身可选 M，偏好宽松可选 XL，具体还看商品版型说明。

**Q：两个尺码之间怎么选？**
A：如果你喜欢合身选小码，喜欢宽松选大码。如果是羽绒服或外套，建议选大码以预留内搭空间。

**Q：我给家人买，不确定尺寸怎么办？**
A：可以拿一件他常穿的同类型衣服，平铺测量胸围和衣长，对照尺码表选择。

**Q：不同品牌的尺码一样吗？**
A：不同品牌可能存在 1-2cm 偏差，建议优先参考具体商品的"尺码详情"页面。
